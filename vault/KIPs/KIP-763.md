## Summary

Currently, state stores in Kafka streams only support bounded ranged queries. More precisely, the range (and reverseRange) interface in the ReadOnlyKeyValueStore look as follows:

/** * Get a reverse iterator over a given range of keys. This iterator must be closed after use. * The returned iterator must be safe from {@link java.util.ConcurrentModificationException}s * and must not return null values. * Order is not guaranteed as bytes lexicographical ordering might not represent key order. * * @param from The first key that could be in the range, where iteration ends. * @param to The last key that could be in the range, where iteration starts from. * @return The reverse iterator for this range, from largest to smallest key bytes. * @throws NullPointerException If null is used for from or to. * @throws InvalidStateStoreException if the store is not initialized */ default KeyValueIterator reverseRange(K from, K to) { throw new UnsupportedOperationException(); }]]>

The requested range is bounded because both the from and the to parameter needs to be a valid object of key type K and must not be null.
