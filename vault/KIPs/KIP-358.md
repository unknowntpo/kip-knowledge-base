## Summary

KAFKA-7277: Right now Streams API universally represents time as ms-since-unix-epoch. There's nothing wrong, per se, with this, but Duration is more ergonomic for an API. What we don't want is to present a heterogeneous API, so we need to make sure the whole Streams API is in terms of Duration.
