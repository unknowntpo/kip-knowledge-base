Currently, Kafka has a backdoor mechanism that allow any client with client ID `__admin_client` to producer to internal topics, bypassing normal internal topic protection. This backdoor can cause several security issues and operation concerns

Security VulnerabilityA malicious or misconfigured client can impersonate the admin client and produce to from internal topics such as: __consumer_offsets, __transaction_state, __share_group_state. This may lead to data corruption, invalid state transitions, or disruption of core Kafka functionality.
