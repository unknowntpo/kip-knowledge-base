## Summary

With the recent deprecation of the #through method in Streams, there is no longer a need for the intermediateTopicsOption in the StreamsResetter tool. The plan is to currently log a warning when this option is used (since it is deprecated), and then in version 5.0 to officially remove it.

StreamsResetter ToolintermediateTopicsOption

We are planning to remove the intermediateTopicsOption from the StreamsResetter tool because with the removal of the #through method there is no longer a use-case/need for this option anymore.
