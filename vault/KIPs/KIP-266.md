## Summary

KafkaConsumer has a long history of indefinite blocking behavior which has been a continual cause of user frustration. This KIP aims to fix this problem in two ways:

We introduce a new configuration default.api.timeout.ms to control the maximum time that current blocking APIs will await before raising a timeout error.

We add overloaded APIs to allow for custom timeout control. This is intended for advanced usage such as in Kafka Streams.
