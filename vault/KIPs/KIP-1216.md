## Summary

When Kafka Streams uses the classic consumer rebalance protocol, it also uses the consumer rebalance listener, which provides metrics to understand the latency of handling lost, revoked and assigned partitions. With the move to a dedicated rebalance protocol (), Kafka Streams does not use the consumer rebalance listener anymore, but instead uses a streams-specific implementation. This KIP proposes to add equivalent metrics for the streams-specific rebalance listener.
