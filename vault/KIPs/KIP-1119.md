## Summary

SSL certificates are typically short-lived, and while Kafka brokers support dynamic SSL certificate reloads via dynamic configuration (), consumers and producers still require disruptive restarts to apply updated certificates. The ability to automatically auto-reload SSL certificate when they are updated eliminates such disruptions and allows for smooth application operations particularly in environments where certificates are rotated automatically by agents.

The goal is to improve system uptime and reduce operational overhead caused by restarts.

The brokers would benefit from the proposed improvement by eliminating the need to run kafka-configs to dynamically update the listeners configuration for certificate rotation.
