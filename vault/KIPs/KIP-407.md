## Summary

I'm using kafka sink connect; The config "auto.offset.reset" is set in connect-distributed*.properties; It works for all connector which in one worker; So the consumer will poll records from latest or earliest; I can not control the 'auto.offset.reset' connector configs post with rest api;

I think is necessary to override worker kafka api configs with connector configs;

With the improvement, connectors with different auto.offset.reset policy can be exist in the same worker;
