In Scala its considered best practice that when you use case class's you create them as final rather than non final (if possible). There are many reasons behind this

case class's are are representation of ADT's which is a functional structure designed to only hold data. case class's do not typically define any behavior, they may define methods but this is typically only calculations based on existing fields inside a case classIf you want classic style OOP where you want inheritance then you use a standard class instead
