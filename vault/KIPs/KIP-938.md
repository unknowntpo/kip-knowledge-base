## Summary

The motivation of this KIP is to add some more metrics for the purpose of measuring performance. Most of these metrics are focused on KRaft mode.

We propose adding the following new metrics:

kafka.controller:type=KafkaController,name=TimedOutBrokerHeartbeatCount Controller Long KRaft only The number of broker heartbeats that timed out on this controller since the process was started. Note that only active controllers handle heartbeats, so only they will see increases in this metric.
