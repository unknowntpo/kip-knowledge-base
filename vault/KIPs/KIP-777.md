## Summary

This KIP is a 3rd attempt to bring consistency and testability to the Admin client's *Result classes. It follows two KIPs which were not accepted:

which proposed to make all the constructors public on the grounds of making it easier to users to write tests with mock Admin instances.

which proposed to deprecate the existing public constructors (most are currently package-private) and eventually revert them all to package-private, on the grounds of making it easier to evolve the overall Admin API in a compatible way.
