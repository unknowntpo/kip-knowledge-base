## Summary

For several years, we have been developing a new way to run Kafka with self-managed metadata. This new mode, called KRaft mode, addresses many urgent scalability and performance issues in Kafka. It also eliminates the need to run an Apache ZooKeeper cluster alongside every Kafka cluster. See for more details.

In Kafka 2.8, KRaft mode was released in early access. By Kafka 3.0, it was in preview.

Mark KRaft as production-ready for new clusters in the upcoming Kafka 3.3 release.
