Currently when we use deleteTopics API with topic deletion disabled on server, then the client cannot get a response and fails returning a timeout error. This KIP is to return proper error code in above mentioned scenario.

If topic deletion feature is disabled , DeleteTopicsAPI response will return TOPIC_DELETION_DISABLED error code.
