## Summary

Current partition method only accepts key and value. Wanted to provide support for selecting partition based on headers too. This lets users pass values to partitioner method without tampering the key and value.

Few of the use cases where this can be helpful :

The user has a header which provides priority of the message [lets say 0 to 9]. You have 10 partitions which you want to use for each priority. With headers available in partition method the partition can be chosen based on the header value. Currently, there is an implementation which achieve the functionality by appending the header value to the key and stripping it off in the keySerializer when creating the keyBytes. This is a hacky solution.
