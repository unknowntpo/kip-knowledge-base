## Summary

introduces new status in consumer group like group epoch, target assignment epoch, member epoch, and target assignment. Adding this information to kafka-consumer-groups.sh and kafka-share-groups.sh commands can help administrator to have a detailed view of the state of the groups.

Add new fields groupEpoch and targetAssignmentEpoch. The ConsumerGroupDescription can be used for classic and consumer group. For classic group, there is no epoch information, so using Optional for new fields.

javaConsumerGroupDescriptiontrue members; private final String partitionAssignor; private final GroupType type; private final ConsumerGroupState state; private final Node coordinator; private final Set authorizedOperations; private final Optional groupEpoch; private final Optional targetAssignmentEpoch;
