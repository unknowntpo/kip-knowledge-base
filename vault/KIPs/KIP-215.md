## Summary

Gwen Shapira describe the motivation well in the JIRA:

KafkaConsumer supports both a list of topics or a pattern when subscribing. KafkaConnect only supports a list of topics, which is not just more of a hassle to configure - it also requires more maintenance.

We should provide a configuration option for Connect sinks to specify a regular expression instead of an explicit topic list.
