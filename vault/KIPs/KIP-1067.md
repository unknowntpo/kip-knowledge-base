## Summary

kafka-replica-verification.sh (org.apache.kafka.tools.ReplicaVerificationTool) has existed since 0.8.1 (KAFKA-1117) but has been rarely used for quite some time, without significant updates also.

The release of 5.0 is a good time to remove this tool, but before that, we have to deprecate it.

Deprecate ReplicaVerificationTool in 3.9.That is, mark ReplicaVerificationTool deprecated but keep it in-place. The kafka-replica-verification.sh tool should be modified to include a deprecation warning. (see: )
