## Summary

In Kafka Streams the KStream interface has several transformValues methods, where as the KTable interface does not. The related mapValues method is available on both KTable and KStream. The transformValue method is more flexible than mapValues:

Stateful implementations. transformValues accepts a supplier of transformers, rather than the mapper instance mapValues accepts. The supplier is used to instantiate a transformer per stream task, meaning the implementation does not need to be thread-safe. Conversely, mapValues shares the passed in mapper instance across stream tasks, so the implementations must be thread-safe.

State-store access: transformValues allows access to existing state-stores, where as mapValues does not.
