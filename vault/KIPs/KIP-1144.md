## Summary

This KIP introduces a new REST API tailored for MirrorMaker2 operational requirements. Tries to make the interaction with MirrorMaker2 easier by providing a new abstraction layer on top of Connect, that can hide the implementation details, and avoid managing the connectors directly.

This proposal introduces a set of REST endpoints for MirrorMaker2 to expose operational status and control information for replication flows. The design greatly reduce the amount of endpoints compared to the Connect REST API, and keep only the essential ones. Built on top of the Connect functionality, this KIP introduces new endpoints built specifically for MirrorMaker2 while applying the same BasicAuthSecurityRestExtension based on JAAS. With these endpoints, operators and tools can query the state of MirrorMaker2 deployments, enabling easier monitoring.
