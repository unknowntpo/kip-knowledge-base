## Summary

KIP-203 implemented support to convert Kerberos principal name to lower case Linux user name via auth_to_local rules. As a follow-up, KafkaShortnamer can be further extended to allow converting principal names to uppercase by appending /U to the rule.

One use-case is given here: ASF JIRA5aa69414-a9e9-3523-82ec-879b028fb15bHADOOP-13984

We propose to extend "sasl.kerberos.principal.to.local.rules" config rule format/syntax by supporting an optional "/U" (toUpperCase) at the end of the rule. Since usernames are locale insensitive strings, we propose to use Locale.ENGLISH for the case conversion
