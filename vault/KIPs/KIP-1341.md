## Summary

ClientQuotaEntity.ConfigEntity#name() returns the placeholder string "<default>" for default quota entities. This is problematic on three counts:

Inconsistent with every other Kafka public API. Across Kafka — Admin client, KRaft records — a default client-quota entity is represented by null, not by a placeholder string. ConfigEntity#name() is the only public surface still returning "<default>", which KAFKA-16411 already designated as a ZooKeeper-internal detail.

Opaque origin. "<default>" is a ZooKeeper-era artifact (znode paths like /config/users/<default>) with no semantic meaning in KRaft-only Kafka.
